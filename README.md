Conversational agents on the Anthropic Claude API, mobile applications in Flutter, and the backend and payment infrastructure behind them.

### Focus areas

**LLM agents** — Conversational agents on the Anthropic Claude API with tool use, operating over text and real-time voice. Agents read live data through tools and execute bounded actions; the action surface is defined by the tool layer rather than by prompt instructions.

**Mobile** — Flutter applications for iOS and Android, published and maintained on the App Store and Google Play through continuous releases.

**Backend** — Node.js and TypeScript services. REST APIs, WebSockets, role-based access control.

**Payments** — Card and mobile payments, bank transfer validation, automated settlements, commission engines, in-app wallet and fiscal electronic invoicing.

**Computer vision** — Identity verification by face matching and document capture with on-device OCR.

**Automation** — Python classifier matching catalog products by image, brand and barcode: 1,172 products at approximately 99% accuracy.

### Selected work

**[ia-local-all-in-one](https://github.com/gilberthrocagr/ia-local-all-in-one)** — Local LLM stack running on a single consumer GPU: llama.cpp with a Qwen3 MoE model, ComfyUI / Z-Image, Goose and FramePack. Native Windows, no containers. Benchmarked, with measured throughput.

Production work for the delivery platform is closed source.
